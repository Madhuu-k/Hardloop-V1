# HARDLOOP V1.1

# Overview 

Hardloop is a behavior-aware productivity and feedback system designed to help students plan realistic workloads and understand the gap between intention and execution.
Unlike traditional productivity apps that rely on fixed planning and manual tracking, Hardloop uses a closed-loop feedback architecture:

1. The user inputs their daily state
2. The system predicts expected completion capacity
3. Tasks are assigned accordingly
4. The user completes work
5. Actual performance is recorded
6. The system measures prediction error
7. Future predictions are adjusted using self-correction

# Tech Stack (V1)

Backend - FastAPI

Database - PostgreSQL

Prediction System - Rule-based scoring engine
